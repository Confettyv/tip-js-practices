## 4. Модель данных и функции

Задача это объект `{ id, title, completed, priority }`:

- `id`: положительное безопасное целое (`Number.isSafeInteger(id) && id > 0`), строки не приводятся;
- `title`: строка, после `trim()` от 1 до 100 символов, в объект пишется очищенная строка;
- `completed`: при создании всегда `false`, при изменении принимается только `true` или `false`;
- `priority`: строго `low`, `medium` или `high`, по умолчанию `medium`.

| Файл | Что в нём |
|---|---|
| `src/data.js` | `demoTasks`, номер варианта и `variantTasks` |
| `src/task-service.js` | девять функций, без `console.log` и без своих данных |
| `src/task-extra.js` | расширение `getPrioritySummary` |
| `src/main.js` | сценарии и вывод |
| `my-checks.js` | мои проверки |

Все функции изменения возвращают `{ ok: true, tasks }` с новым массивом или `{ ok: false, error }`. `createTask` при успехе возвращает `{ ok: true, task }`. Повторяющиеся проверки `id` и названия вынесены во внутренние функции `isValidId` и `checkTitle`.

**Почему id не равен индексу:** индекс меняется после удаления, а `id` у задачи остаётся. Например, после удаления `id 7` задача `id 10` переехала с индекса 3 на индекс 2.  
**Почему getTaskStats возвращает число:** с числом ещё можно считать и сравнивать. `toFixed(1)` даёт строку, поэтому округляю только при выводе в `main.js`.  
**Какие объекты копируются при изменении:** новый массив через `map` и новый объект только у изменённой задачи (`{ ...task, completed }`). Остальные задачи переходят в новый массив теми же объектами, их никто не меняет.

## 8. Расширение

Выполнен вариант Б: `getPrioritySummary(tasks)` в `src/task-extra.js`. Возвращает `{ low, medium, high }`, у каждого `{ total, pending }`. Все три ключа есть всегда, даже если задач с таким приоритетом нет. Считаю обычным циклом `for...of`, исходный массив не меняется.

Для `demoTasks` получилось: `low` 1 / 1, `medium` 2 / 0, `high` 1 / 1, как в методичке. Проверены смешанный набор, пустой список и список с одним приоритетом (последние три строки вывода `my-checks.js`).
